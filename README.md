Socialmedia-C
A social networking application built with C# and .NET that enables users to create profiles, share posts, comment on content, and interact within a simple online community.

Overview
This project was developed as a practical social media platform to explore common backend and application design patterns used in user-centric systems.

It demonstrates how to structure a modular application around:

user management
content creation
interaction workflows
maintainable code organization
Key Features
User registration and authentication
User profile creation and management
Posting and sharing content
Commenting on posts
Basic user interaction within the network
Modular structure for easier maintenance and extension
Tech Stack
Language: C#
Framework: .NET
UI: Windows Forms / .NET Desktop
Database: SQL Server
IDE: Visual Studio
Project Goals
The main purpose of this project was to practice building a social platform and applying core software engineering concepts such as:

separation of concerns
reusable logic
data-driven application design
user-focused features
clean and maintainable code
Architecture
The project follows a modular structure that separates:

UI layer for user interaction
Business logic for application rules
Data layer for persistence and database operations
This structure makes the codebase easier to understand, maintain, and extend.
